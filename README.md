# 🛍️ Application E-commerce Mobile – Flutter & Laravel

## 📌 Présentation

Dans le cadre de mon stage, j’ai eu l’opportunité de travailler sur le développement complet d’une application mobile de commerce électronique. Le projet repose sur **Flutter** pour la partie frontale (application mobile) et **Laravel** pour le backend (API RESTful).

Cette expérience m’a permis de :
- Mettre en pratique mes compétences en développement mobile et web.
- Explorer des technologies modernes et performantes.
- Apprendre à résoudre des problèmes techniques concrets.

🎯 **Objectif principal** : Développer une plateforme robuste, fluide et sécurisée, offrant aux utilisateurs une expérience d’achat mobile intuitive.

---

## 🧰 Technologies utilisées

### 🖥️ Frontend (Mobile)
- [Flutter](https://flutter.dev/) – Framework multiplateforme
- Dart – Langage principal
- Provider – Gestion d’état
- Dio / HTTP – Communication API REST
- SharedPreferences – Stockage local

### 🌐 Backend (Laravel)
- [Laravel](https://laravel.com/) – Framework PHP MVC
- API RESTful – Interface avec l’app mobile
- JWT (JSON Web Token) – Authentification sécurisée
- MySQL – Base de données relationnelle

---

## 🚀 Fonctionnalités clés

Voici les principales fonctionnalités développées dans l'application :

- 🔐 Création de comptes utilisateurs et authentification
- 🔍 Recherche avancée de produits
- 🧭 Navigation fluide par catégories
- 🛒 Ajout de produits au panier
- 📦 Gestion des commandes
- 👤 Gestion du profil utilisateur
- 🔔 Notifications (optionnel avec Firebase)
- 📱 Design responsive et expérience utilisateur optimisée

Chaque fonctionnalité a été développée en tenant compte :
- Des **besoins des utilisateurs**
- Des **exigences du marché mobile**
- De la **sécurité des données**
